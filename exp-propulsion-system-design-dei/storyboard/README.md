## Storyboard

Experiment 1: Propulsion System Design: Propeller Geometry, Thrust & Motor Matching

### 1. Story Outline
This experiment is the foundational propulsion experiment of the drone virtual lab. Students are dropped into a realistic systems engineering workflow to complete a full, interdependent design loop.

### 2. Story

#### 2.1 Set the Visual Stage Description:
The visual stage displays a virtual drone test bench. There are interactive components for selecting propeller size, motor KV rating, and battery voltage. A real-time data readout shows thrust, RPM, and efficiency curves.

#### 2.2 Set User Objectives & Goals:
The user must systematically design and validate a complete drone propulsion system by calculating the minimum required hover thrust, selecting optimal propeller geometry, and matching a motor that operates stably and efficiently.

#### 2.3 Set the Pathway Activities:
The user first inputs the mass budget to find required thrust. Then they lock the RPM and sweep propeller sizes to see the thrust generation. After finding the right propeller, they select a motor KV and battery to see if it can spin the propeller under load. Finally, they map the efficiency curve.

##### 2.4 Set Challenges and Questions/Complexity/Variations in Questions:
The main challenge is balancing the interdependent variables. A larger propeller creates more thrust but requires a lower KV motor to avoid overloading. Students must find the optimal combination that peaks at 60% throttle.

##### 2.5 Allow pitfalls:
If a student selects a very high KV motor with a large propeller, the simulator will show the motor overheating and RPM dropping drastically due to extreme current draw and internal resistance.

##### 2.6 Conclusion:
Upon successful completion, the PROPELLERS + MOTORS unlock and physically mount onto the drone frame. The specific motor efficiency curve generated by the student is stored and carried forward to be used in future experiments.
